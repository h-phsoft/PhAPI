## Synonyms as table names

1209 tables are emitted under their Oracle synonym name.

Oracle defines a table under one name and a synonym over it, and the foreign
keys, views and seed data all reference the synonym. Neither target has
synonyms, and neither allows a foreign key to reference a view, so emitting
synonyms as views would break every constraint that uses one. Renaming the
table to its synonym keeps all existing references valid.
