# Project Rules

## Code Style
- Never use TAB. Always use 2 spaces for indentation.
- Every indentation level is exactly 2 spaces.
- Never write `if`, `else`, `for`, `while`, or `do` without `{}` braces.

## Enforcement
- `.editorconfig` at project root enforces 2-space indentation.
- ESLint `curly` rule enforces mandatory braces for JS/TS files.
